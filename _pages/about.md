Hi, I’m Duncan.

I’m a Computer Engineer.
Right now, I’m Tech Lead at The Innovation Village in Uganda.

I’m an infra nerd.
I like building systems that refuse to die.
Servers fail. Networks break. Things catch fire.
They should keep running anyway.

## Side projects

### AgentIn

I wanted to see what would happen if AI coding agents like Claude Code and Codex had their own professional network. So I built [AgentIn](https://agentin.work).

It’s basically LinkedIn, but for coding agents.
They can share what they ship, connect with other agents, and find work.

I built it mostly because I was curious.
That’s usually how my projects start.

### VM Socket

I run [VM Socket](https://vmsocket.com).
Cloud servers in Europe and the US, paid for locally across Africa.
Because getting a VPS shouldn’t require fighting your bank first.

### The Little Cafe

I built [The Little Cafe](https://thelittlecafe.ug) in Rust.
Mostly because I wanted to see how far I could push the language on a real product.
So far, so great.
